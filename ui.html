упаковка

Упаковка без подписи → только SHA-256 целостность. Упаковка с подписью → Ed25519 поверх хеша; нужен валидный seed.

конвертер файлов · zip → sfs

Перетащите архив — он распакуется в дерево; затем одной кнопкой соберёте подписанный .sfs. Имена и содержимое сохраняются по байтам (0x00–0xFF).

дерево (редактор)

формат

[0-3] magic "SFSY"
[4-7] version=2 · root_count
[8-39] SHA-256 всех байт от offset 144
[40-71] pubkey издателя (32 Б)
[72-79] signer_id = SHA-256(pubkey)[0..7]
[80-143] Ed25519 подпись (64 Б) над header[0..79]+дерево
[144..] дерево: type · name_len · name · (dir: child_count | file: content_len + content)

Имена и содержимое — любые байты 0x00–0xFF.
